# Mac 앱 버전 이력

`mac-app/VERSION` 파일의 값이 빌드 시 앱에 박히고(좌측 패널 하단 표시), 빌드
날짜가 자동 첨부됩니다 (`bundle.sh`). 기능을 추가하면 **VERSION을 올리고 여기에
한 줄 적는다.** 그러면 받는 사람이 앱 하단에서 자기 버전을 확인할 수 있다.

> 버전을 올리는 곳: `mac-app/VERSION` (예: `v1.3` → `v1.4`).
> shared/public dmg는 자동 갱신 안 됨 — 버전 올리면 `package-dmg.sh`로 재빌드.

## v1.5 — 2026-06-21 (안정성)
- **앱 멈춤(응답 없음) 수정**: Start 시 `AVAudioEngine`(mic) 초기화 + 장치 열거
  (`refreshDevices`)가 메인스레드에서 CoreAudio HAL을 동기 호출해 UI가 통째로
  얼던 문제. 둘 다 백그라운드 큐로 이동 → HAL이 느려도 UI는 안 멈춤.
- **CoreAudio 누수/폭주 방지**: 시스템오디오(SCStream) stop 시
  `removeStreamOutput` + `stopCapture`로 확실히 닫고, 앱 종료 시에도 자동 정리
  (`applicationWillTerminate`). 반복 start/stop·강제종료로 coreaudiod가 안 닫힌
  스트림을 쌓아 폭주하던 것 차단.
